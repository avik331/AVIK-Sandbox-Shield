# Example: Cryptographic Audit Log Structure

Below is an example of what the `blockchain.json` file generated by Layer 7 looks like.

Notice how each block mathematically ties to the `previous_hash`, ensuring the chronological order cannot be rearranged. If someone tries to change the payload in Block 1, `block_hash` 1 will change, which will break the `previous_hash` link in Block 2, invalidating the entire chain.

## Verifying the Ledger
To verify the ledger in an actual forensic scenario, the investigator runs the `MerkleTree.verify_integrity()` function, supplying the known-good Merkle Root hash (which is typically backed up to a secure WORM drive daily) and the `blockchain.json` file.
